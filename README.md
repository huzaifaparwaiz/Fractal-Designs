# Fractal Design

## Project Description

**Fractal Design** is a visualisation project that demonstrates the beauty and mathematical structure of fractals. The project generates different types of fractal patterns using programming, allowing users to explore how simple mathematical rules can create complex and detailed designs.

## Fractals Implemented

The project includes multiple fractal designs, including:

* Koch Snowflake
* Fractal Tree
* Sierpinski Triangle
* Mandelbrot Set
* And other fractal patterns

## Libraries Used

The project was developed using the following libraries:

* **Python**
* **Turtle**
* **NumPy**
* **Matplotlib**

## Setup and Run Instructions

### 1. Clone the Repository

```bash
git clone <[YOUR-GITHUB-REPOSITORY-URL](https://github.com/huzaifaparwaiz/Fractal-Designs)>
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd Fractal-Design
```

### 3. Install Required Libraries

Install the required Python libraries using:

```bash
pip install numpy matplotlib
```

> The `Turtle` library is included with standard Python installations in most cases.

### 4. Run the Project

Run the main Python file:

```bash
python main.py
```

Follow the instructions displayed by the program to view the different fractal designs.
